# Operator Scripts

Week 6 will add small Bash/Python utilities. The purpose is to automate repetitive support checks, not build a software product.

Planned examples:

- `service-check.sh` — service, listening port and HTTP health checks
- `disk-check.sh` — disk threshold with useful output and exit code
- Python API checker — request, JSON parsing, status/error handling and logging

Every script should be understandable in an interview and safe to run in its documented scope.
