# Week 2 — Linux Troubleshooting & System Administration

**Dates:** 21–26 September 2026

## Outcome

Troubleshoot Linux services systematically using logs, resources, SSH, permissions and storage/process evidence, then fix safely or escalate well.

## Evidence checklist

- [ ] `runbooks/linux-service-troubleshooting.md`
- [ ] Service-failure incident
- [ ] Permission or storage incident
- [ ] SSH/access incident
- [ ] Saturday blind Linux incident

## Diagnostic flow

Confirm symptom/impact → host/resources → process/service → ports/dependencies → logs around failure time → hypothesis/test → fix/escalate → verify.
